# Qozaiym 👁️

**Qozaiym** is an AI-powered navigation assistant designed to empower visually impaired individuals by providing real-time environmental awareness and safe navigation guidance.

## 🌟 Overview
Developed for the **Infomatrix** competition, Qozaiym leverages computer vision and AI to bridge the gap between technology and accessibility. The application acts as a "digital eye," identifying obstacles, recognizing objects, and helping users navigate complex environments with confidence.

## 🚀 Key Features
* **AI Object Recognition:** Real-time identification of everyday objects using advanced computer vision.
* **Obstacle Detection:** High-precision warnings to ensure user safety during movement.
* **Voice Feedback:** Natural language audio cues to provide seamless interaction for the user.
* **Flutter-Based Interface:** A responsive and accessible UI/UX designed specifically for accessibility needs.

## 🛠️ Tech Stack
* **Framework:** Flutter (Dart)
* **AI/ML:** Integrated Computer Vision models for object detection.
* **Category:** AI Programming

## 📂 Project Structure
* `lib/` - Core application logic and Flutter UI components.
* `assets/` - Machine learning models and sound files for voice feedback.
